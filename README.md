# 📝 Django Todo Application

A clean, responsive, and functional **Todo List (Task Manager)** application built using Python and the **Django Framework**. This project demonstrates core CRUD operations and relational database management.

## 🚀 Key Features
* **Create Tasks:** Easily add new tasks with dynamic titles and detailed descriptions.
* **Update Status:** Mark tasks as completed with a single click (toggles line-through styling).
* **Delete Tasks:** Completely remove outdated or unwanted tasks from the database.
* **Auto-Timestamp:** Automatically tracks when each task was created using `DateTimeField`.

## 🛠️ Tech Stack & Concepts
* **Backend:** Python 3.x, Django Web Framework
* **Database:** SQLite (Default Django ORM)
* **Frontend:** Clean HTML5 & Custom CSS (Fully Responsive RTL Design)
* **Architecture:** MVC / MVT (Models, Views, Templates) Pattern
